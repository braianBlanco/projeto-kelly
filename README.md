# Projeto Kelly — V4 | Nossa História

Projeto pessoal desenvolvido com **Python + Flask + HTML + CSS + JavaScript**.

## Como executar

No VS Code, abra a pasta `projeto-kelly` e rode no terminal:

```cmd
pip install -r backend\requirements.txt
python backend\app.py
```

Depois abra:

`http://127.0.0.1:5000`

## Música
Coloque uma música que você tenha autorização para usar em:

`frontend/assets/audio/musica.mp3`

O botão de música é ativado depois que o navegador permite a reprodução.

## Estrutura

- `backend/app.py` — servidor Flask e dados
- `backend/requirements.txt` — dependências
- `frontend/index.html` — estrutura
- `frontend/css/style.css` — identidade visual e responsividade
- `frontend/js/main.js` — interações, API, galeria e música
- `frontend/assets/photos/` — fotos
- `frontend/assets/audio/` — música autorizada

## Ideia

A V4 foi construída para parecer um pequeno projeto web cinematográfico, e não uma página simples. O conteúdo usa memórias reais fornecidas pelo autor e mantém uma linguagem afetiva sem transformar a página em uma cobrança ou exigência de resposta.
